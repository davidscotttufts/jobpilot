# Outcome calibration → (much later) bandit

Tier 3 — Intelligence & Efficiency · Status: **todo**

## What

Join `score-fit` scores with `scan-inbox` outcomes: interview rate by score band / board /
resume variant / role family, shown in analytics. Pooled cross-user priors second. Automated
reallocation (contextual bandit) only when per-user data supports it — per-user N is tens of
applications with weeks of outcome delay; don't start there (see [deferred.md](deferred.md)).

## Why

Turns the product from an apply machine into a strategy engine; both halves (prospective scoring
and outcome classification) already exist — nothing connects them.

## Done when

Analytics shows "your interview rate by score band / board / variant" from real joined data.
