# Getting started

JobPilot has two halves: a hosted dashboard and an agent that runs on your
machine. Setup takes about ten minutes.

## What you need

- A [Claude Code](https://claude.com/claude-code) or [Codex](https://openai.com/codex)
  subscription. The agent runs on it - JobPilot needs no API keys.
- Windows, macOS, or Linux.

## 1. Install the plugin

Add the plugin to the provider you use - the [install page](/install) has
copy-paste commands for both. In Claude Code:

```text
/plugin marketplace add https://github.com/suxrobgm/claude-plugins
/plugin install jobpilot@sukhrob-claude-plugins
```

In Codex, from a shell:

```text
codex plugin marketplace add suxrobGM/codex-plugins
codex plugin add jobpilot@sukhrob-codex-plugins
```

## 2. Run setup

Start a new provider session and run the `setup` skill - `/jobpilot:setup` in
Claude Code, `$setup` in Codex. It installs the local terminal host, starts
the agent, and opens the dashboard.

```text
/jobpilot:setup
$setup
```

From here the agent dock - the terminal panel in the dashboard's bottom
corner - shows everything the agent does, and you can switch providers there
any time. If the terminal host ever breaks, the [install page](/install) has
a one-line installer to repair it.

## 3. Create your account

1. Go to [jobpilot.suxrobgm.net](https://jobpilot.suxrobgm.net) and sign up.
2. Verify your email address.
3. Complete onboarding: fill in your profile and upload a resume PDF. The
   running agent parses the resume into the structured editor; the profile
   powers form filling, the resume powers job scoring and tailoring.
4. Check the suggested rewrite. The agent proposes an improved version - sharper
   summary, outcome-first bullets, tidier skill groups - and lists every change.
   Nothing applies until you press **Apply**, and your PDF is never modified, so
   re-extracting always gets you back to the original.

Everything can be changed later under **Settings**.

> Keep your profile address and resume header in agreement. Recruiters read the
> resume, but application forms and cover-letter headers come from your profile -
> the resume page flags any disagreement.

## 4. Run your first campaign

Start gentle: search first, apply after review.

```text
/jobpilot:search senior typescript remote
$search senior typescript remote
```

The agent searches the board you pick, scores each role against your resume,
and saves the matches to a campaign. Review the ranked list, then let it
apply to the ones you approve.

Once you trust the scoring, go autonomous:

```text
/jobpilot:auto-apply senior typescript remote
$auto-apply senior typescript remote
```

Auto-apply searches, scores, and applies one job at a time until the board
is exhausted, you pause it, or it reaches your application cap (set under
**Settings → Profile**).

Every application lands in your workspace, where it moves from applied to
offer. Next up: [Campaigns & skills](/docs/campaigns-and-skills).
